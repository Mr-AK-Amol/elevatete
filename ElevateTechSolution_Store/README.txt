EMAIL
Project inquiries are addressed to elevatetechsolution.co@gmail.com.
The form uses a mailto link, so it opens the visitor's configured email app with a pre-filled message. It does not send mail silently in the background. For automatic form delivery, connect a form backend or email service.

RIGHT-CLICK / INSPECT LIMITATION
The site disables the context menu and intercepts common shortcuts such as F12, Ctrl+Shift+I/J/C, and Ctrl+U as a basic deterrent. This is not real source-code protection. Visitors can still access page source, developer tools, network resources, or downloaded files through other methods. Never put passwords, API secrets, or private data in front-end files.

DEPLOYMENT
Upload all files into the same website root folder (often public_html). Keep filenames and relative paths unchanged. Test every page, mobile navigation, template filters, and the contact form. Enable HTTPS for elevatetechsolution.store.
